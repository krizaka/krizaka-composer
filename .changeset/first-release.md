First release of Krizaka Composer, the Krizaka fork of Puck: the package is `@krizaka/composer`, with the versioned `ComposerDocument` (schema 2) in `@krizaka/composer/document` (zod validation with error paths, nested typed slots, words per locale, variables and bindings, asset references with a MIME allow-list, a server-side `validateDocument`, the migration from the shop page of schema 1). Rich text, external fields, and the upstream create-app, Contentful, emotion and docs packages are gone.
